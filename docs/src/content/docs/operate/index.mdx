A cluster is a set of `merod` nodes. In production each runs in an attested
Intel TDX VM, takes its storage key from mero-kms, and holds the replicas of the
apps placed on it; one Raft log per app keeps the replicas identical, and one
system log holds accounts, organizations, packages and the fleet. You drive it
with `meroctl`, and the operator's side goes through the Ops API with an ops
token, which reports counts and placement and never reads app data.

New to Calimero? Read the [Cloud overview](/cloud/overview/) first, then the
[Quickstart](/cloud/quickstart/).
