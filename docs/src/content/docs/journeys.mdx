Each journey threads pages across tracks in the order that gets you to a goal.
Follow one top to bottom.

## Build a collaborative app

<Steps>

1. [Quickstart](/cloud/quickstart/) — a local cluster, an app, a call from the CLI and from code.
2. [Build your first app](/build/tutorial/) — state, methods, build, call.
3. [Writing apps for release-v2](/cloud/apps/) — what a cluster changes: identity, organizations, teams, handlers, timers, outbound.
4. [Collections](/build/collections/) — the state types your app is built from.
5. [Emit &amp; handle events](/build/guides/events/) and [call another app](/build/guides/cross-context/).
6. [Packaging &amp; signing](/build/packaging-signing/) — ship a signed release; [migrations](/build/migrations/) for the next one.

</Steps>

## Run a production cluster

<Steps>

1. [Calimero Cloud](/cloud/overview/) — what runs where, and the trust model in one page.
2. [Operating a cluster](/operate/deployment/) — the storage key, peers, governance, the Ops API.
3. [Deployment governance](/protocol/governance/) — decide who approves images, app upgrades and outbound hosts before the first start.
4. [The operator &amp; the Ops API](/protocol/operator/) — what you can do, and what you deliberately cannot.
5. [Replication](/protocol/replication/) — joining nodes, replica moves, snapshots, failover.
6. The [`merod`](/operate/merod/) and [`meroctl`](/operate/meroctl/) references.

</Steps>

## Understand how a cluster works

<Steps>

1. [Protocol overview](/protocol/overview/) — the one idea everything hangs on.
2. The model: [Concepts](/protocol/concepts/) → [The system group](/protocol/system-group/) → [Replication](/protocol/replication/).
3. The call path: [Execution](/protocol/execution/) → [The write path](/protocol/write-path/) → [Reads, views &amp; events](/protocol/reads/).
4. Trust: [Networking &amp; sealed channels](/protocol/networking/) → [Attestation &amp; receipts](/protocol/tee-attestation/) → [Encryption](/protocol/encryption/) → [Security &amp; threat model](/protocol/security-model/).
5. People: [Accounts &amp; sessions](/protocol/identities/) → [Who a run acts as](/protocol/authorship/) → [Organizations &amp; teams](/protocol/organizations/).
6. Look things up: [Storage schema](/protocol/storage/), [Limits](/protocol/limits/), [Glossary](/protocol/glossary/).

</Steps>

## Prove to a user where their data lives

<Steps>

1. [Attestation &amp; receipts](/protocol/tee-attestation/) — the quote, the measurement policy, `verify_app_cluster`.

3. [Encryption](/protocol/encryption/) — the storage key from mero-kms and what an observer still sees.
4. [Security &amp; threat model](/protocol/security-model/) — including what is not protected yet.

</Steps>
