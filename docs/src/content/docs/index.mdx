## Why Calimero

<CardGrid>
  <Card title="Private by default" icon="seti:lock">
    Your app's data is encrypted and stays inside sealed hardware. Not the
    server operator, not Calimero, not anyone else can read it.
  </Card>
  <Card title="Proof, not promises" icon="approve-check">
    Before sending anything, your app checks that it is talking to a genuine,
    unmodified server. Every answer comes back signed.
  </Card>
  <Card title="Always in sync" icon="random">
    Every app runs on several servers at once and keeps them in step, so it
    stays up and nothing is lost if one goes down.
  </Card>
  <Card title="Works where you are" icon="laptop">
    Sign in with a passkey, no passwords. Call your app from the web, iOS or
    Android with our client libraries.
  </Card>
</CardGrid>
