## Everything your app needs, out of the box

Cloud providers sell confidential hardware and leave the rest to you: keys,
storage, backups, upgrades, permissions. Calimero supplies all of it, so you
ship in days or weeks instead of years.

<CardGrid>
  <Card title="Sign-in" icon="seti:lock">
    Passkey sign-in, sessions and scoped API keys.
  </Card>
  <Card title="Database" icon="seti:db">
    Your app's data, replicated across servers: maps, sets, tables and rich
    text.
  </Card>
  <Card title="Functions" icon="seti:rust">
    App logic in Rust, plus background jobs, timers and pipelines.
  </Card>
  <Card title="Realtime" icon="random">
    Live updates and presence pushed to every client.
  </Card>
  <Card title="Files and search" icon="document">
    Sealed file storage and full-text search over your app's data.
  </Card>
  <Card title="Clients" icon="laptop">
    Ready-made TypeScript, Python, Swift and Kotlin clients.
  </Card>
</CardGrid>

## Private, and you can prove it

<CardGrid>
  <Card title="Sealed servers" icon="approve-check">
    Before your app sends anything, it checks that the server is genuine,
    unmodified hardware, and then talks to it only over an encrypted channel.
  </Card>
  <Card title="Encrypted at rest" icon="seti:lock">
    A server gets its disk key only after proving which software it runs. A
    copied disk or a tampered server reads nothing.
  </Card>
  <Card title="You approve every change" icon="setting">
    New code reaches your data only after the approver you choose signs off.
    Calimero can't push an update on its own.
  </Card>
  <Card title="Open source" icon="github">
    The runtime, node and SDK are open source (Apache 2.0), and every answer
    comes back with a signed receipt you can check.
  </Card>
</CardGrid>

## Run it your way

Start on **Calimero Cloud**, where small apps share hardware and cost a
fraction of a dedicated machine. Move to a **dedicated cluster** or **your own
infrastructure** when you need to, without rewriting your app.
