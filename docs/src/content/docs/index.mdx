## Architecture at a glance

```text
client (meroctl · mero-js · calimero-client-py · calimero-client)
   │  verify the TDX quote → Noise NK session to the attested key → sealed requests
   ▼
any merod node ──── system group (group 1, every node): accounts, orgs, packages, app directory
   │  forward over a peer sealed channel
   ▼
the app's leader ── runs the WASM call, appends { call, outcome { result, diff, events } }
   │  Raft
   ▼
the app's followers ── apply the diff (nobody re-executes)
```
