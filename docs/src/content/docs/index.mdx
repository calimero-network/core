## Architecture at a glance

<ClusterArchitecture />

A client verifies a node's TDX attestation, then talks to any node through a
sealed channel. That node checks the caller against the cluster's system group
and forwards the call to the leader of the app's own Raft group, which runs the
component and replicates the resulting diff to the app's other replicas; the
answer comes back with a receipt signed by an attested key. [More in Calimero Cloud →](/cloud/overview/)
