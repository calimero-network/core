## Architecture at a glance

<ClusterArchitecture />

A client verifies a node's TDX attestation, then talks to any node through a
sealed channel. That node checks the caller against the cluster's system group
and forwards the call to the app's leader, which runs the WASM and replicates
the result to the app's other replicas. [More in Calimero Cloud →](/cloud/overview/)
