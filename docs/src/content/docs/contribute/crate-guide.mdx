Every workspace member, grouped by role. The [architecture orientation](/contribute/architecture/)
shows how they fit; each crate's `AGENTS.md` (with a `CLAUDE.md` symlink
beside it) has its commands and detail. The same index, for agents, is
[`crates/AGENTS.md`](https://github.com/calimero-network/core/blob/master/crates/AGENTS.md).

## Binaries

| Crate | Package | What it is |
| --- | --- | --- |
| `crates/merod` | `merod` | The node binary: `init`, `run`, `config`, `local`, `inspect`, `kms disk-key`. Turns `NodeArgs` into the node's `Config`. |
| `crates/meroctl` | `meroctl` | The command line for nodes, v1's command tree over the attested, sealed client. |

## The node

| Crate | Package | What it is |
| --- | --- | --- |
| `crates/cloud-node` | `calimero-cloud-node` | The node: system group, app groups, executor glue, routing, the HTTP API and Ops API, packages, follow-ups, blobs, presence, search, app frontends, backups, the storage key. |
| `crates/log` | `calimero-log` | Multi-group Raft (openraft) over one sealed RocksDB per node; snapshots; the `log.redb` migration. |
| `crates/sealed` | `calimero-sealed` | The sealed HTTP transport (wire format v2), server middleware and client; byte-compatible with mero-js. |
| `crates/identity` | `calimero-identity` | WebAuthn passkeys, session tokens, API keys, confirm challenges; `testing`: a software authenticator. |
| `crates/cloud-client` | `calimero-cloud-client` | The Rust client: attestation check (shared with peers), sealed requests, sign-in, calls and views. |
| `crates/kms-client` | `calimero-kms-client` | The mero-kms client: release-policy check, key release, `kms disk-key`. |
| `crates/outbound` | `calimero-outbound` | The gated outbound HTTPS client and secrets a run may use. |
| `crates/search` | `calimero-search` | Per-app full-text search (tantivy), built in memory from apps' search exports. |

## Attestation and releases

| Crate | Package | What it is |
| --- | --- | --- |
| `crates/tee-attestation` | `calimero-tee-attestation` | TDX quote generation (Linux, configfs-tsm) and DCAP verification; `mock-attestation` for tests; the `calimero-tee-verify` binary behind `cli`. |
| `crates/tee-release` | `calimero-tee-release` | Fetches and Sigstore-verifies signed mero-tee release assets (`published-mrtds.json`, KMS policies). |

## Packages

| Crate | Package | What it is |
| --- | --- | --- |
| `crates/bundle` | `calimero-bundle` | The `.mpk` manifest, JCS canonicalization and Ed25519 signatures; shared with `cargo-mero` and `mero-sign`. |
| `crates/app-downloader` | `calimero-app-downloader` | Fetching signed releases from a package registry (`HttpRegistry`). |

## SDK and runtime

Unchanged from v1, so v1 apps deploy as they are. The runtime is being
replaced; check with its owner before changing these.

| Crate | Package | What it is |
| --- | --- | --- |
| `crates/sdk` (+ `sdk/macros`) | `calimero-sdk`, `calimero-sdk-macros` | The app SDK: `#[app::state]`, `#[app::logic]`, events, migrations, `TestHost`. |
| `crates/storage` | `calimero-storage` | CRDT collections and the storage interface apps write through; the `converge` harness. |
| `crates/storage-macros` | `calimero-storage-macros` | Derive macros for storage entities. |
| `crates/sys` | `calimero-sys` | The WASM host ABI types and imports. |
| `crates/wasm-abi` | `calimero-wasm-abi` | The `wasm-abi/1` schema, validation and the embedded custom section the node reads. |
| `crates/prelude` | `calimero-prelude` | The root storage key derivation shared by SDK and storage. |
| `crates/runtime` | `calimero-runtime` | The wasmer runtime with gas metering and the host functions; the node's executor runs it. |

## Shared types

| Crate | Package | What it is |
| --- | --- | --- |
| `crates/primitives` | `calimero-primitives` | Ids, keys, hashes and wire types used everywhere. |
| `crates/account` | `calimero-account` | `AccountId` (and v1's device ids and credentials); the node uses `AccountId`. |

## Runtime-only v1 crates

These are v1 node crates kept only because `calimero-runtime` still links them.
Nothing in the release-v2 node uses them directly. Do not build on them.

| Crate | Package | Kept for |
| --- | --- | --- |
| `crates/node/primitives` | `calimero-node-primitives` | The runtime's `NodeClient` (blob host functions); pulls in the crates below. |
| `crates/context/config` | `calimero-context-config` | Types the runtime names (`GovernanceParentEdge`), and `governance-types`. |
| `crates/network/primitives` | `calimero-network-primitives` | Through `node-primitives`. |
| `crates/governance-types` | `calimero-governance-types` | Through `node-primitives`. |
| `crates/store` (+ `store/impl/rocksdb`) | `calimero-store`, `calimero-store-rocksdb` | Through `node-primitives`, and the runtime's tests. |
| `crates/store/blobs` | `calimero-blobstore` | Through `node-primitives`. |
| `crates/utils/actix` | `calimero-utils-actix` | Through `node-primitives`. |
| `crates/crypto` | `calimero-crypto` | The runtime's sealing of values to keys (`seal_to_root`, `open_sealed`). |

## Build and development

| Crate | Package | What it is |
| --- | --- | --- |
| `crates/build-utils` | `calimero-build-utils` | `build.rs` helpers: release version, git and rustc metadata. |
| `crates/git-hooks` | `calimero-git-hooks` | Installs `.githooks/pre-commit` (`cargo fmt --check`) on any build. |

## Tools

| Tool | Binary | What it is |
| --- | --- | --- |
| `tools/cargo-mero` | `cargo-mero` | The app toolchain: scaffold, build (with the embedded ABI), test, bundle and sign a `.mpk`. |
| `tools/calimero-abi` | `mero-abi` | Extract, embed, inspect and diff app ABIs. |
| `tools/mero-sign` | `mero-sign` | Sign bundle manifests. |
| `tools/storage-cost` | `storage-cost` | Deterministic storage-cost counts and the cost gate snapshot. |
| `tools/storage-compare` | `storage-compare` | Storage workloads measured against a chosen `calimero-storage`. |
| `tools/state-disk-cost` | `state-disk-cost` | On-disk RocksDB bytes per state entry under column-family options. |
