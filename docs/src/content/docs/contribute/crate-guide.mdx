Every workspace member, grouped by role; a crate not listed here does not
exist. The [architecture orientation](/contribute/architecture/) shows how they
fit, in dependency layers; each crate's `AGENTS.md` (with a `CLAUDE.md` symlink
beside it) has its commands and detail. The same index, for agents, is
[`crates/AGENTS.md`](https://github.com/calimero-network/core/blob/master/crates/AGENTS.md).

## Binaries

| Crate | Package | What it is | Spec |
| --- | --- | --- | --- |
| `crates/merod` | `merod` | The node binary: `init`, `run`, `config`, `local`, `inspect`, `kms disk-key`, `attest`. Turns `NodeArgs` into the node's `Config`. | [merod CLI reference](/operate/merod/), [Configuration](/operate/config/) |
| `crates/meroctl` | `meroctl` | The command line for nodes, over the attested, sealed client. | [meroctl CLI reference](/operate/meroctl/) |

## The app runtime

Apps are `calimero:app` components on wasmtime. Check with their owner before
changing these.

| Crate | Package | What it is | Spec |
| --- | --- | --- | --- |
| `crates/app-wit` | `calimero-app-wit` | The `calimero:app` WIT world and its import allow-list. | [App execution](/protocol/execution/), [The env API](/build/host-functions/) |
| `crates/app-host` | `calimero-app-host` | The engine-neutral host core of `calimero:app`: state, policy, time and randomness. | [App execution](/protocol/execution/), [The env API](/build/host-functions/) |
| `crates/app-engine-wasmtime` | `calimero-app-engine-wasmtime` | The wasmtime engine for components: fuel, epochs, limits and a checked cache. | [One run](/protocol/execution/#one-run), [Limits](/protocol/limits/) |
| `crates/sdk` (+ `sdk-macros`) | `calimero-sdk`, `calimero-sdk-macros` | The Rust app SDK for `calimero:app`: app attributes, encoding, tables, collections, env and the embedded ABI. | [Build Calimero apps](/build/), [SDK macros](/build/sdk-macros/), [Tables & collections](/build/collections/) |
| `crates/app-sdk` | `calimero-app-sdk` | The SDK's old name: re-exports `calimero-sdk`, kept until no app depends on it. | [Build Calimero apps](/build/) |
| `crates/app-build` | `calimero-app-build` | Builds Rust guests into `calimero:app` components; behind `meroctl app build`, `meroctl app codegen` and `meroctl app abi diff`. | [Packaging & signing](/build/packaging-signing/) |
| `crates/app-abi` | `calimero-app-abi` | An app's ABI for clients: the OpenAPI document the node serves, typed TS/Python clients, breaking-change checks. | [App interface (ABI)](/build/app-abi/), [Typed clients](/build/guides/typed-clients/) |
