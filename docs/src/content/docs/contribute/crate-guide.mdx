Every workspace member, grouped by role; a crate not listed here does not
exist. The [architecture orientation](/contribute/architecture/) shows how they
fit, in dependency layers; each crate's `AGENTS.md` (with a `CLAUDE.md` symlink
beside it) has its commands and detail. The same index, for agents, is
[`crates/AGENTS.md`](https://github.com/calimero-network/core/blob/master/crates/AGENTS.md).

## Binaries

| Crate | Package | What it is |
| --- | --- | --- |
| `crates/merod` | `merod` | The node binary: `init`, `run`, `config`, `local`, `inspect`, `kms disk-key`, `attest`. Turns `NodeArgs` into the node's `Config`. |
| `crates/meroctl` | `meroctl` | The command line for nodes, over the attested, sealed client. |

## The node

| Crate | Package | What it is |
| --- | --- | --- |
| `crates/node` | `calimero-node` | The node: system group, app groups, executor glue, routing, the HTTP API and Ops API, packages, follow-ups, blobs, sealed files, compute and pipeline runs, the job node, the consent page, presence, search, app frontends, backups and the recovery disk, the storage key. |
| `crates/log` | `calimero-log` | Multi-group Raft (openraft) over one sealed RocksDB per node; snapshots; the `log.redb` migration. |
| `crates/sealed` | `calimero-sealed` | The sealed HTTP transport (wire format v2), server middleware and client; byte-compatible with mero-js. |
| `crates/identity` | `calimero-identity` | WebAuthn passkeys, session tokens, API keys, confirm challenges; `testing`: a software authenticator. |
| `crates/client` | `calimero-client` | The Rust client: attestation check (shared with peers), sealed requests, sign-in, and a route layer generated from the node's OpenAPI document (`client.<group>().<method>()`). |
| `crates/kms-client` | `calimero-kms-client` | The mero-kms client: release-policy check, key release, `kms disk-key`. |
| `crates/outbound` | `calimero-outbound` | The gated outbound HTTPS client and secrets a run may use. |
| `crates/search` | `calimero-search` | Per-app full-text search (tantivy), built in memory from apps' search exports. |

## The app runtime

Apps are `calimero:app` components on wasmtime. Check with their owner before
changing these.

| Crate | Package | What it is |
| --- | --- | --- |
| `crates/app-wit` | `calimero-app-wit` | The `calimero:app` WIT world and its import allow-list. |
| `crates/app-host` | `calimero-app-host` | The engine-neutral host core of `calimero:app`: state, policy, time and randomness. |
| `crates/app-engine-wasmtime` | `calimero-app-engine-wasmtime` | The wasmtime engine for components: fuel, epochs, limits and a checked cache. |
| `crates/sdk` (+ `sdk-macros`) | `calimero-sdk`, `calimero-sdk-macros` | The Rust app SDK for `calimero:app`: app attributes, encoding, tables, collections, env and the embedded ABI. |
| `crates/app-sdk` | `calimero-app-sdk` | The SDK's old name: re-exports `calimero-sdk`, kept until no app depends on it. |
| `crates/app-build` | `calimero-app-build` | Builds Rust guests into `calimero:app` components; behind `meroctl app build`, `meroctl app codegen` and `meroctl app abi diff`. |
| `crates/app-abi` | `calimero-app-abi` | An app's ABI for clients: the OpenAPI document the node serves, typed TS/Python clients, breaking-change checks. |

## Build and development

| Crate | Package | What it is |

## Tools

| Tool | Binary | What it is |
| --- | --- | --- |
| `tools/mero-sign` | `mero-sign` | The signing library behind `meroctl app signer\|sign\|pack`; no binary. |
| `tools/mero-compute` | `mero-compute` | Runs one compute method of a compute component alone, with a job node's engine and caps: the library behind `meroctl local compute run`; no binary. |
| `tools/client-gen` | `calimero-client-gen` | Generate `calimero-client`'s route layer from `docs/public/openapi.json`; its test fails while the checked-in code is stale. |
| `tools/search-bench` | `search-bench` | `calimero-search`'s engine over the node's in-memory directory: index size, query latency, memory, the search-gas fit (`benchmarks.yml` uploads its report). |
