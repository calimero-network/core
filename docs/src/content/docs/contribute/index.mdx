Calimero Core is a Rust workspace: the node (`merod` over
`calimero-node`), its command line (`meroctl`), the Raft log, the sealed
transport, identity and attestation crates, the app SDK and WASM runtime, the
example apps under `apps/` and the tools under `tools/`.

## Start here

<Steps>

1. Read the **[architecture orientation](/contribute/architecture/)**: what is inside a node and the path of a call.
2. Find your crate in the **[crate guide](/contribute/crate-guide/)**, then read its `AGENTS.md`.
3. Set up the **[development workflow](/contribute/development/)**: build, run a local cluster, the checks before a PR.
4. Read the **[testing strategy](/contribute/testing/)** before writing a test.

</Steps>
